Turso (SQLite)

Hai máy dùng chung một database Turso: bạn bạn giao task, bạn nộp báo cáo (từng phiên bản), bản nháp cũng theo sang máy kia. Tạo database free ở turso.tech → copy URL + auth token dán vào đây (mỗi máy một lần).

Token lưu trong trình duyệt máy này. Khi kết nối, dữ liệu máy này được gộp lên DB (bản mới hơn thắng) rồi kéo toàn bộ về.

Dữ liệu

Backup JSON của day, task (mọi file), checklist, báo cáo và bản nháp (không gồm token Turso).

Nhập backup thay thế dữ liệu máy này; lần "Kết nối & đồng bộ" sau sẽ gộp phần mới hơn lên Turso.
